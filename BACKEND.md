# Retained native backend

`vendor/coil` is an immutable snapshot of Coil revision b7a54594b42820c24c4b4cce0d9348f160bdd38e. `snapshot.json` records every imported file's SHA-256 and original path. Authored DSLs, their Coil implementations, generated modules, runtime, adapters and independent tests are retained together. Copyright and license notices remain at their original paths. No old frontend/checker/Program lowering is imported.

Reproduce the import with `python3 tools/vendor-backend.py ../coil`; verify it against the original Git objects with `--check`. The importer refuses to overwrite divergent files. Backend changes must originate in the authored DSL sources and be regenerated, with a deliberate snapshot/version update; never patch generated output alone.

Run `python3 tools/check-backend.py` to verify file hashes, reproduce the 77 generated modules, and execute the retained direct-CIR suite locally. The suite compares interpreted and compiled CIR behavior for arithmetic, loop/SSA construction, calls and wide operations. Its own failure count becomes the process exit status. Output and compiler hash are recorded in `evidence/backend-baseline.json`. This establishes the snapshot's macOS baseline, not full rewrite parity or Linux validation.

`tests/backend/Coil.toml` deliberately resolves the generated snapshot rather than running readers during every backend consumer build. Run that package from its own directory (`cd tests/backend && coil run`); invoking its entry under the repository-root project selects different source roots.

The new lowering should construct `native.cir/Func` and invoke the retained direct or graph path. `tests.direct` demonstrates construction, compilation and in-memory linking independently of the old frontend. The upcoming slice must exercise branch merges and direct calls, preserve source origins, and execute code generated by this backend. The schema/judgment frontend is not connected to it yet. Object emission, ABI classification and full debug data remain additional integration work.

Include retained authored DSLs, language machinery and runtime in the 45,000-line accounting. Generated output and backend tests are separately reported; being vendored does not exempt authored production code from the budget.
